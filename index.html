IoT Wearable for Sleep Cycle Analysis & Smart Alarming

Project Overview

Tired of jarring alarms disrupting your sleep? We designed and developed a compact, low-cost, and energy-efficient IoT wearable that accurately monitors heart rate variability to analyze sleep cycles. The ultimate goal is to integrate this data into a smart alarm system that gently wakes users during their lightest sleep phase, promoting better rest and cognitive function. This project spanned custom hardware design, embedded firmware development, and mobile application creation.

The Challenge:

The primary challenge was to create a sophisticated yet affordable wearable capable of continuous, accurate physiological monitoring (specifically Photoplethysmography - PPG) over an 8-hour sleep period. This required:

  • Meticulous component selection for cost and power efficiency
  • Robust signal processing to extract clean heart rate data from noisy PPG signals
  • Seamless data transmission to a mobile device for analysis and user interaction

Our Innovative Solution

Custom Wearable Hardware
×
  • Sensing: A custom analog front-end featuring a green LED and an SFH 2430 photodiode captures blood volume changes. Our unique photodiode configuration, differing from standard Transimpedance Amplifiers (TIAs), empirically yielded cleaner signals.
  • Signal Conditioning: A multi-stage op-amp (MCP6004) circuit filters and amplifies the raw PPG signal, isolating the desired frequency band (0.48Hz - 33.86Hz).
Dual-Processor Architecture for Power Efficiency
  • STM8S003F3 Microcontroller: An ultra-low-power MCU responsible for ADC sampling of the conditioned PPG signal at a precise 50Hz (strategically using aliasing to mitigate 50Hz noise). It buffers 2.5 seconds of data (125 bytes) before waking the ESP32.
  • ESP32-C3 Mini Module: Manages Bluetooth Low Energy (BLE) communication, aggregates data from the STM8S into a 10-second (500-byte) buffer (stored in RTC memory during its deep sleep cycles), and handles FreeRTOS for task management.
  • Power Management: A LiPo battery, MCP73831 BMS for USB-C charging, and a TCR2EF33 LDO ensure stable power delivery and efficient operation.
  • Ergonomics: A custom-sewn fabric wristband with memory foam provides comfort and blocks ambient light for improved sensor accuracy.
Embedded Firmware
  • STM8S (C): Programmed for precise interrupt-driven ADC sampling, data buffering, and UART communication to the ESP32. Manages system power-down via LDO control.
  • ESP32 (ESP-IDF, FreeRTOS, C++): Implements a BLE GATT server with custom 128-bit UUIDs for secure and unique device identification. Manages deep sleep cycles, waking every 2.5 seconds to receive data from STM8S via UART, and waking fully every 10 seconds to transmit the aggregated 500-byte buffer to the mobile app. Mutexes and semaphores ensure synchronized data handling.
×
Mobile Application (Flutter)
  • BLE Client: Scans for and connects to the wearable using its custom UUID, requesting data in 20-byte chunks (BLE 4.0 limit) when the ESP32 signals a full buffer.
  • Digital Signal Processing (DSP): Implements a Fast Fourier Transform (FFT) on the incoming raw PPG data. To enhance resolution without increasing firmware complexity or power drain, a circular buffer on the app aggregates 50 seconds of data (2500 samples), achieving a 1.2 BPM frequency resolution.
  • User Interface: Displays real-time BPM, features a fully functional alarm clock (timezone-aware, 12/24hr format, snooze), and a dark theme for low-light environments.

Key Achievements & Impact

Accuracy Validated

Achieved a strong Pearson correlation coefficient (R = 0.873) when compared against a commercial Fitbit Inspire 2 device for heart rate monitoring.

×
Significant Power Efficiency

Optimized firmware and a dual-MCU strategy extended battery life to 16.84 hours on a 245mAh battery, an 8-fold improvement over a non-optimized baseline, suitable for overnight sleep tracking.

Cost-Effective Design

The Bill of Materials (BOM) demonstrated a potential production cost of just 49 DKK (~€6.50 / $7.00) per unit in bulk, making it highly competitive.

End-to-End System Integration

Successfully designed, built, and tested a complete system from sensor hardware to a functional mobile application.

Novel Power-Saving Strategy

The symbiotic relationship between the ultra-low-power STM8S for continuous sensing and the ESP32 for periodic, power-managed communication was key to achieving extended battery life.

Custom Potentiostat with Python User Interface

Project Overview

This project involved the development of a complete electrochemical measurement system, featuring a high-precision potentiostat with an intuitive Python-based user interface. The system enables researchers and engineers to perform various electrochemical techniques with laboratory-grade accuracy at a fraction of the cost of commercial instruments.

Key Objectives:
  • Achieve sub-nanoamp current measurement resolution
  • Support multiple electrochemical techniques (CV, CA, EIS, etc.)
  • Develop an intuitive, feature-rich Python GUI for experiment control
  • Create a modular design for easy customization and upgrading

Technical Implementation

Hardware Architecture

The potentiostat hardware was designed with a focus on precision and noise immunity:

  • Analog Front-End: Precision op-amps (OPA192, AD8608) configured as potentiostat control loop
  • Current Measurement: Transimpedance amplifier with switchable gain stages (1nA to 100mA ranges)
  • DAC/ADC: 16-bit DAC for potential control, 24-bit delta-sigma ADC for current measurement
  • Microcontroller: STM32F4 series MCU handling real-time control, measurement, and communication
  • Isolation: Full galvanic isolation between the measurement circuit and computer interface
Firmware Architecture

The firmware implements a robust control system with several features:

  • Real-time potential control with PID feedback loop
  • Multiple electrochemical technique implementations (Cyclic Voltammetry, Chronoamperometry, etc.)
  • Adaptive sampling rate based on signal dynamics
  • USB Communication protocol with command validation and error handling
  • Onboard data buffering to ensure no data loss during high-speed measurements
Python GUI Development

The user interface was built using PyQt5 with a focus on usability:

  • Intuitive experiment setup with parameter validation
  • Real-time data visualization using Matplotlib integration
  • Automated data analysis tools for common electrochemical parameters
  • Data export in multiple formats (CSV, JSON, specialized formats)
  • Automated report generation capabilities

Challenges & Solutions

Low-Current Measurement Noise

Achieving sub-nanoamp measurement resolution required careful PCB layout and shielding. I implemented a multi-layer PCB with guard rings, dedicated analog ground planes, and strategic component placement to achieve a noise floor below 500 pA peak-to-peak.

Wide Dynamic Range

Electrochemical measurements often span 6+ orders of magnitude in current. I designed an auto-ranging system with seamless gain switching and overlapping ranges to provide accurate measurements from 1nA to 100mA without manual intervention.

Real-Time Performance

High-speed techniques like Fast-Scan Cyclic Voltammetry require precise timing and rapid data acquisition. I implemented a dual-core architecture where one core handles critical timing while the second manages communication and non-time-critical tasks.

Results & Impact

The completed potentiostat system delivers impressive performance metrics:

  • Current measurement range: ±1nA to ±100mA with auto-ranging
  • Potential control range: ±2V with 100μV resolution
  • Maximum sampling rate: 10kHz for high-speed techniques
  • Cost: Approximately 15% of comparable commercial instruments

This instrument has been successfully deployed in multiple research laboratories and has enabled several publications in electrochemical sensors and materials characterization. The open-source design has also been adopted and modified by researchers worldwide for specialized applications.
