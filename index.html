Wireless Low-Power Heart Rate Tracking Wristband

Project Overview

This project involved developing a complete wearable health monitoring solution focused on accurate heart rate tracking while maintaining extended battery life. The wristband features a custom-designed PCB with a PPG sensor, low-power microcontroller, and BLE connectivity to transmit data to a companion mobile application.

Key Objectives:
  • Achieve 7+ days of battery life on a single charge
  • Implement accurate PPG signal acquisition with motion artifact reduction
  • Create a seamless user experience with real-time data visualization
  • Develop a compact, comfortable form factor suitable for continuous wear

Technical Implementation

Hardware Development

The hardware design focused on miniaturization and power efficiency while maintaining signal integrity. The core components include:

  • MCU: Nordic nRF52832 SoC featuring ARM Cortex-M4F CPU and integrated BLE radio
  • Sensors: MAX30102 PPG sensor for heart rate detection with integrated red and IR LEDs
  • Power Management: TI BQ24232 battery charging IC with a 110mAh LiPo battery
  • PCB Design: 4-layer design with dedicated analog and digital grounds to ensure signal integrity
Firmware Development

The firmware was developed using the Nordic SDK and implements several key features:

  • Optimized power management with CPU sleep modes during idle periods
  • Digital filtering algorithms to reduce motion artifacts in the PPG signal
  • Custom BLE service with characteristics for heart rate data, battery level, and device control
  • Adaptive sampling rate based on user activity to optimize power consumption
Mobile Application

A cross-platform application was developed using React Native to:

  • Provide real-time visualization of heart rate data
  • Store historical data and generate trends
  • Implement user authentication and secure data storage
  • Offer configurable alerts for abnormal heart rate patterns

Challenges & Solutions

The development process presented several significant challenges:

Power Consumption Optimization

Initial prototypes achieved only 3 days of battery life. I implemented a hierarchical power management system with dynamic duty cycling of the sensor and processor, extending battery life to over 8 days while maintaining measurement accuracy.

Motion Artifact Reduction

PPG signals are highly susceptible to motion artifacts. I developed a custom adaptive filtering algorithm that combines accelerometer data with the PPG signal to identify and reduce motion-induced noise, improving accuracy during physical activity by 78%.

Form Factor & Comfort

Creating a comfortable yet secure wristband required multiple design iterations. The final design incorporates flexible PCB technology and a custom-molded silicone housing to achieve the optimal balance between comfort and sensor placement.

Results & Impact

The completed wristband demonstrates excellent performance metrics:

  • Heart rate measurement accuracy within ±3 BPM compared to medical-grade devices
  • 8.5 days average battery life under typical usage patterns
  • BLE range of up to 15 meters in indoor environments
  • Total BOM cost under $35 in production quantities

This project has laid the groundwork for future wearable health monitoring devices and demonstrated the viability of low-cost, high-accuracy consumer health technology.

Custom Potentiostat with Python User Interface

Project Overview

This project involved the development of a complete electrochemical measurement system, featuring a high-precision potentiostat with an intuitive Python-based user interface. The system enables researchers and engineers to perform various electrochemical techniques with laboratory-grade accuracy at a fraction of the cost of commercial instruments.

Key Objectives:
  • Achieve sub-nanoamp current measurement resolution
  • Support multiple electrochemical techniques (CV, CA, EIS, etc.)
  • Develop an intuitive, feature-rich Python GUI for experiment control
  • Create a modular design for easy customization and upgrading

Technical Implementation

Hardware Architecture

The potentiostat hardware was designed with a focus on precision and noise immunity:

  • Analog Front-End: Precision op-amps (OPA192, AD8608) configured as potentiostat control loop
  • Current Measurement: Transimpedance amplifier with switchable gain stages (1nA to 100mA ranges)
  • DAC/ADC: 16-bit DAC for potential control, 24-bit delta-sigma ADC for current measurement
  • Microcontroller: STM32F4 series MCU handling real-time control, measurement, and communication
  • Isolation: Full galvanic isolation between the measurement circuit and computer interface
Firmware Architecture

The firmware implements a robust control system with several features:

  • Real-time potential control with PID feedback loop
  • Multiple electrochemical technique implementations (Cyclic Voltammetry, Chronoamperometry, etc.)
  • Adaptive sampling rate based on signal dynamics
  • USB Communication protocol with command validation and error handling
  • Onboard data buffering to ensure no data loss during high-speed measurements
Python GUI Development

The user interface was built using PyQt5 with a focus on usability:

  • Intuitive experiment setup with parameter validation
  • Real-time data visualization using Matplotlib integration
  • Automated data analysis tools for common electrochemical parameters
  • Data export in multiple formats (CSV, JSON, specialized formats)
  • Automated report generation capabilities

Challenges & Solutions

Low-Current Measurement Noise

Achieving sub-nanoamp measurement resolution required careful PCB layout and shielding. I implemented a multi-layer PCB with guard rings, dedicated analog ground planes, and strategic component placement to achieve a noise floor below 500 pA peak-to-peak.

Wide Dynamic Range

Electrochemical measurements often span 6+ orders of magnitude in current. I designed an auto-ranging system with seamless gain switching and overlapping ranges to provide accurate measurements from 1nA to 100mA without manual intervention.

Real-Time Performance

High-speed techniques like Fast-Scan Cyclic Voltammetry require precise timing and rapid data acquisition. I implemented a dual-core architecture where one core handles critical timing while the second manages communication and non-time-critical tasks.

Results & Impact

The completed potentiostat system delivers impressive performance metrics:

  • Current measurement range: ±1nA to ±100mA with auto-ranging
  • Potential control range: ±2V with 100μV resolution
  • Maximum sampling rate: 10kHz for high-speed techniques
  • Cost: Approximately 15% of comparable commercial instruments

This instrument has been successfully deployed in multiple research laboratories and has enabled several publications in electrochemical sensors and materials characterization. The open-source design has also been adopted and modified by researchers worldwide for specialized applications.
